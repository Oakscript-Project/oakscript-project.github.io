OakBoot 0.1.0 preview

A separate Windows compiler for native x64 UEFI programs. The boot machine needs no OS, OakScript runtime or DLLs. The compiler computer needs MinGW-w64 x64 GCC.

.\oakboot.exe .\examples\boot-demo.oak -o demo.efi --image demo.img

# Genuine held-key input on compatible PS/2 hardware:
.\oakboot.exe .\examples\boot-demo.oak -o demo-ps2.efi --image demo-ps2.img --bare-metal --keyboard ps2

Copy the compiled EFI file to EFI\BOOT\BOOTX64.EFI on a FAT32 USB drive and select its UEFI boot entry. Firmware must allow this unsigned program. The package also includes a QEMU launcher and ready-made demo images.

The renderer runs on the CPU and writes to the firmware-initialized framebuffer. Native resolution depends on the modes firmware exposes. The raw backend exits UEFI boot services and polls a PS/2 controller. The default firmware keyboard backend produces short keystroke pulses.

This preview has no accelerated GPU backend, native USB HID state driver, general speaker/headphone audio, legacy BIOS boot or full OakScript compatibility. Physical ASUS and other motherboard testing is still missing. Sound is limited to compatible PC-speaker tones.

Generated images have been tested under QEMU/OVMF at 1920×1080 with pixel checks, held-key/release checks and captured PC-speaker tones. Emulator measurements do not establish physical-hardware performance or compatibility.
