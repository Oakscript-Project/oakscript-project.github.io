OakScript

GitHub

A general-purpose programming language with built-in graphics, audio, and GPU compute.

Download OakScript

v0.7.0 - Windows x64

Console programs need no extra runtimes. The runner's graphics require a Vulkan-capable driver.

Example file

def square(int value) -> int:(
    return value * value
)

int total = 0
for value in range(1, 6):(
    total += square(value)
)
print("Total:", total)

To run:

.\oakscript.exe filename.oak

Output:

Total: 55
